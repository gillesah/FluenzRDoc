# Analytics

FluenzR ofrece analíticas completas para medir y optimizar tus campañas.

## Vista general

### Panel de campaña

Para cada campaña, accede a las estadísticas haciendo clic en la pestaña **Estadísticas**.

### Métricas principales

| Métrica | Descripción | Fórmula |
|--------|-------------|---------|
| **Enviados** | Número de emails enviados | - |
| **Entregados** | Emails que llegaron a destino | Enviados - Rebotes |
| **Aperturas** | Contactos que abrieron | Aperturas únicas |
| **Clics** | Contactos que hicieron clic | Clics únicos |
| **Respuestas** | Contactos que respondieron | Respuestas detectadas |
| **Bajas** | Contactos dados de baja | - |
| **Rebotes** | Emails no entregados | - |

## Tasas de rendimiento

### Tasa de apertura

```
Tasa de apertura = Aperturas únicas / Entregados × 100
```

| Rendimiento | Tasa |
|-------------|------|
| Excelente | >40% |
| Bueno | 25-40% |
| Promedio | 15-25% |
| Bajo | <15% |

### Tasa de clics

```
Tasa de clics = Clics únicos / Entregados × 100
```

| Rendimiento | Tasa |
|-------------|------|
| Excelente | >5% |
| Bueno | 2-5% |
| Promedio | 1-2% |
| Bajo | <1% |

### Tasa de respuesta

```
Tasa de respuesta = Respuestas / Entregados × 100
```

| Rendimiento | Tasa |
|-------------|------|
| Excelente | >5% |
| Bueno | 2-5% |
| Promedio | 1-2% |
| Bajo | <1% |

### Tasa de rebote

```
Tasa de rebote = Rebotes / Enviados × 100
```

| Rendimiento | Tasa |
|-------------|------|
| Excelente | <2% |
| Aceptable | 2-5% |
| Problemático | >5% |

> **Advertencia**
Una tasa de rebote >5% puede impactar tu capacidad de entrega. Limpia tu lista de contactos.

## Interpretar tus resultados

### Buena tasa de apertura, baja tasa de clics

**Diagnóstico:** El asunto atrae pero el contenido no convence.

**Acciones:**
- Mejora tu propuesta de valor
- Añade un CTA más claro
- Prueba contenido más corto

### Baja tasa de apertura

**Diagnóstico:** El asunto no incentiva la apertura.

**Acciones:**
- Personaliza el asunto con variables
- Prueba diferentes enfoques (pregunta, número, etc.)
- Verifica tu reputación de remitente

### Muchas aperturas, pocas respuestas

**Diagnóstico:** Los prospectos están interesados pero no convencidos.

**Acciones:**
- Simplifica tu petición (llamada corta)
- Añade prueba social
- Facilita la acción (enlace Calendly)

### Tasa alta de rebote

**Diagnóstico:** Calidad de lista problemática.

**Acciones:**
- Limpia tu lista de contactos
- Usa un servicio de validación de emails
- Verifica tus fuentes de recopilación

## Comparación de campañas

Compara el rendimiento de múltiples campañas:

1. Ve a **Campañas**
2. Selecciona las campañas a comparar
3. Haz clic en **Comparar**

|--------|------------|------------|-----|

| Respuestas | 3.2% | 2.1% | +52% |
