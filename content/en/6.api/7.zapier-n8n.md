# Zapier and n8n

FluenzR connects to Zapier and n8n: a reply comes in, a prospect is interested, a meeting is booked, and your other tools (Google Sheets, Slack, Notion, your CRM…) follow, with no code.

> **ℹ️ Info**
API keys are available on the **Pro** plan only.

## 1. Create an API key

1. In FluenzR, open **Settings** > **Integrations** > **Zapier and n8n**.
2. Name the key (for example "Zapier") and click **Create a key**.
3. Copy the key (it starts with `flz_`). It is shown only once.

The key gives access to your contacts and campaigns: do not share it. You can delete it at any time from the same page.

## What you can automate

| Trigger | When |
|---|---|
| Reply received | a prospect replies to an email |
| Prospect interested | a contact is marked Interested in the Inbox (by you, the AI or a rule) |
| Email sent | FluenzR sends an email |
| Contact added | a contact is added to FluenzR |
| Meeting booked | a prospect books a meeting |
| LinkedIn invitation accepted | a prospect accepts your invitation |

| Action | Effect |
|---|---|
| Create or update a contact | creates the contact, or completes the one with the same email (tags are added) |
| Add to a campaign | enrolls an existing contact; if FluenzR declines (already prospected, already in another campaign) the response says `added: 0` with the reason |
| Pause | pauses the contact in all campaigns |
| Stop in a campaign | permanently stops sending in one campaign |
| Add a tag | adds a tag without removing the others |

## Zapier

1. Open the FluenzR app in Zapier (the link appears in **Settings** > **Integrations** > **Zapier and n8n** once available).
2. Create a Zap and pick FluenzR as the trigger or the action.
3. When connecting, paste your API key.

Triggers subscribe by themselves when you turn the Zap on, and unsubscribe when you turn it off.

## n8n

1. In n8n: **Settings** > **Community Nodes** > **Install**, then enter `n8n-nodes-fluenzr`.
2. Create **FluenzR API** credentials with your key.
3. Add the **FluenzR Trigger** node (trigger) or the **FluenzR** node (actions).

> **⚠️ Warning**
FluenzR must be able to reach your n8n at a public address: n8n Cloud works, and a self-hosted n8n needs `WEBHOOK_URL` set. Local or private addresses are refused.

### n8n templates

Import them in n8n with **Import from URL**:

- Reply received to Slack: `https://docs.fluenzr.co/n8n/reponse-vers-slack.json`
- Prospect interested to Google Sheets: `https://docs.fluenzr.co/n8n/interesse-vers-google-sheets.json`
- New lead to a campaign: `https://docs.fluenzr.co/n8n/nouveau-lead-vers-campagne.json`

After the import, pick your FluenzR and Slack or Google Sheets credentials, and the campaign for the last template.

## For developers

All routes live under `https://app.fluenzr.co/api/v1/integrations`, with the `X-API-Key` header.

| Route | Purpose |
|---|---|
| `GET /me` | authentication test: returns the key's account |
| `POST /hooks` | subscribe `{ "targetUrl": "https://…", "event": "EMAIL_REPLIED" }`; returns `{ "id": "…" }` |
| `DELETE /hooks/{id}` | unsubscribe (no error if it no longer exists) |
| `GET /hooks/sample?event=…` | a sample event |
| `GET /campaigns` | campaigns (id, name, status) |
| `POST /contacts/upsert` | create or update by email |
| `POST /contacts/tags` | `{ "email": "…", "tag": "…" }` |
| `POST /contacts/pause` | `{ "email": "…" }` |
| `POST /campaigns/{id}/contacts` | `{ "email": "…" }` |
| `POST /campaigns/{id}/contacts/stop` | `{ "email": "…", "reason": "…" }` |

Events arrive as a `POST` with this body:

```json
{
  "eventId": "9a2d6f1e-…",
  "eventType": "CONTACT_INTERESTED",
  "timestamp": "2026-10-27T09:30:00Z",
  "data": { "contactId": "…", "email": "marie.dupont@exemple.fr", "firstName": "Marie", "source": "AI" }
}
```

Local or private addresses are refused at subscription. A subscription whose address fails ten times in a row is disabled. Subscriptions created by Zapier and n8n show up in **Integrations** > **Webhooks**, prefixed with `[integration]`.
