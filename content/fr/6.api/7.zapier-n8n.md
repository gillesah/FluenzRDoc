# Zapier et n8n

FluenzR se branche dans Zapier et n8n : une réponse arrive, un prospect est intéressé, un rendez-vous est pris, et vos autres outils (Google Sheets, Slack, Notion, votre CRM…) suivent, sans code.

> **ℹ️ Info**
Les clés API sont réservées au forfait **Pro**.

## 1. Créer une clé API

1. Dans FluenzR, ouvrez **Configuration** > **Intégrations** > **Zapier et n8n**.
2. Donnez un nom à la clé (par exemple « Zapier ») et cliquez sur **Créer une clé**.
3. Copiez la clé (elle commence par `flz_`). Elle n'est affichée qu'une seule fois.

La clé donne accès à vos contacts et campagnes : ne la partagez pas. Vous pouvez la supprimer à tout moment depuis la même page.

## Ce que vous pouvez automatiser

| Déclencheur | Quand |
|---|---|
| Réponse reçue | un prospect répond à un email |
| Prospect intéressé | un contact passe au statut « Intéressé » dans l'Inbox (par vous, l'IA ou une règle) |
| Email envoyé | FluenzR envoie un email |
| Contact ajouté | un contact est ajouté à FluenzR |
| Rendez-vous pris | un prospect prend rendez-vous |
| Invitation LinkedIn acceptée | un prospect accepte votre invitation |

| Action | Effet |
|---|---|
| Créer ou mettre à jour un contact | crée le contact, ou complète celui qui a la même adresse (les étiquettes s'ajoutent) |
| Ajouter à une campagne | inscrit un contact existant ; si FluenzR refuse (déjà prospecté, déjà dans une autre campagne), la réponse indique `added: 0` et la raison |
| Mettre en pause | met le contact en pause dans toutes les campagnes |
| Arrêter dans une campagne | arrête définitivement l'envoi dans une campagne |
| Ajouter une étiquette | ajoute une étiquette sans effacer les autres |

## Zapier

1. Ouvrez l'application FluenzR dans Zapier (lien affiché dans **Configuration** > **Intégrations** > **Zapier et n8n** dès qu'elle est disponible).
2. Créez un Zap, choisissez FluenzR comme déclencheur ou comme action.
3. À la connexion, collez votre clé API.

Les déclencheurs s'abonnent tout seuls quand vous activez le Zap, et se désabonnent quand vous le coupez.

## n8n

1. Dans n8n : **Paramètres** > **Nœuds communautaires** > **Installer**, puis saisissez `n8n-nodes-fluenzr`.
2. Créez des identifiants **FluenzR API** avec votre clé.
3. Ajoutez le nœud **FluenzR Trigger** (déclencheur) ou **FluenzR** (actions).

> **⚠️ Attention**
FluenzR doit pouvoir joindre votre n8n à une adresse publique : n8n Cloud convient, et pour un n8n installé chez vous il faut renseigner `WEBHOOK_URL`. Une adresse locale (`localhost`, réseau privé) est refusée.

### Modèles n8n

Importez-les dans n8n par **Importer depuis une URL** :

- Réponse reçue vers Slack : `https://docs.fluenzr.co/n8n/reponse-vers-slack.json`
- Prospect intéressé vers Google Sheets : `https://docs.fluenzr.co/n8n/interesse-vers-google-sheets.json`
- Nouveau lead vers une campagne : `https://docs.fluenzr.co/n8n/nouveau-lead-vers-campagne.json`

Après l'import, choisissez vos identifiants FluenzR et Slack ou Google Sheets, et la campagne pour le dernier modèle.

## Pour les développeurs

Toutes les routes sont sous `https://app.fluenzr.co/api/v1/integrations`, avec l'en-tête `X-API-Key`.

| Route | Rôle |
|---|---|
| `GET /me` | test d'authentification : rend le compte de la clé |
| `POST /hooks` | abonnement `{ "targetUrl": "https://…", "event": "EMAIL_REPLIED" }` ; rend `{ "id": "…" }` |
| `DELETE /hooks/{id}` | désabonnement (sans erreur si l'abonnement n'existe plus) |
| `GET /hooks/sample?event=…` | un événement d'exemple |
| `GET /campaigns` | campagnes (identifiant, nom, statut) |
| `POST /contacts/upsert` | créer ou mettre à jour par adresse email |
| `POST /contacts/tags` | `{ "email": "…", "tag": "…" }` |
| `POST /contacts/pause` | `{ "email": "…" }` |
| `POST /campaigns/{id}/contacts` | `{ "email": "…" }` |
| `POST /campaigns/{id}/contacts/stop` | `{ "email": "…", "reason": "…" }` |

Les événements arrivent en `POST` avec ce corps :

```json
{
  "eventId": "9a2d6f1e-…",
  "eventType": "CONTACT_INTERESTED",
  "timestamp": "2026-10-27T09:30:00Z",
  "data": { "contactId": "…", "email": "marie.dupont@exemple.fr", "firstName": "Marie", "source": "AI" }
}
```

Les adresses locales ou privées sont refusées à l'abonnement. Un abonnement dont l'adresse échoue dix fois de suite est désactivé. Les abonnements créés par Zapier et n8n apparaissent dans **Intégrations** > **Webhooks**, préfixés par `[integration]`.
