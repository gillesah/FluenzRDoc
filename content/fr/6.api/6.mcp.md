# Brancher une IA (MCP)

Le Model Context Protocol (MCP) permet à une IA comme Claude ou ChatGPT de piloter votre compte FluenzR. L'IA prépare, vous validez : un lancement de campagne attend votre accord dans la page **À valider**, et chaque action d'écriture est journalisée dans « Activité IA ».

## Adresse du serveur

```
https://app.fluenzr.co/api/mcp
```

La connexion se fait avec votre compte FluenzR (OAuth) : aucune clé à copier. La page **Connexion** de l'application affiche cette adresse et les étapes ci-dessous.

## Claude.ai et Claude Desktop

1. Ouvrez **Paramètres**, puis **Connecteurs**.
2. Cliquez sur **Ajouter un connecteur personnalisé**.
3. Collez l'adresse du serveur MCP.
4. Connectez-vous à FluenzR quand la fenêtre d'autorisation s'ouvre.

## Claude Code

```bash
claude mcp add --transport http fluenzr https://app.fluenzr.co/api/mcp
```

Dans Claude Code, tapez `/mcp`, choisissez `fluenzr` et authentifiez-vous.

## ChatGPT (mode développeur)

1. Dans ChatGPT, ouvrez **Paramètres**, puis **Connecteurs**, et activez le **mode développeur**.
2. Créez un connecteur personnalisé et collez l'adresse du serveur MCP.
3. Connectez-vous à FluenzR à l'ouverture de la fenêtre d'autorisation.

L'interface de ChatGPT change souvent : si les libellés diffèrent, cherchez l'ajout d'un connecteur MCP personnalisé.

## Premier message à coller

> Tu es connecté à mon compte FluenzR. Commence par lister mes boîtes d'envoi avec list_email_accounts et résume leurs plafonds. Règles : tu prépares, je valide. Tu crées les groupes et les brouillons de campagne, puis tu appelles start_campaign : le lancement attend ma validation. Tu n'envoies aucune réponse à mes contacts.

Pour une campagne mêlant LinkedIn et email, l'IA crée le brouillon puis ajoute les étapes dans l'ordre (étape LinkedIn, attente, condition, email).

## Votre accord avant le lancement

Dans la page **Connexion**, l'option « Mon accord avant le lancement » demande votre accord avant qu'une IA connectée lance une campagne. Elle est activée par défaut.

## Disponibilité

Le serveur MCP est inclus dans le forfait Pro, essai de 14 jours compris.
