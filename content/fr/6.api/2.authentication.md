# Authentification API

L'API FluenzR utilise des clés API pour l'authentification.

## Obtenir une clé API

### Prérequis

- Plan **Pro** actif
- Droits administrateur sur le compte

### Générer une clé

1. Connectez-vous à FluenzR
2. Allez dans **Paramètres** > **API**
3. Cliquez sur **Générer une nouvelle clé**
4. Donnez un nom descriptif à la clé
5. Copiez immédiatement la clé affichée

> **⚠️ Attention**
La clé n'est affichée qu'une seule fois. Conservez-la en lieu sûr. Si vous la perdez, vous devrez en générer une nouvelle.

## Utiliser la clé API

### Header Authorization

Incluez votre clé API dans le header `Authorization` de chaque requête :

```bash
curl -X GET "https://api.fluenzr.co/v1/contacts" \
  -H "Authorization: Bearer flz_sk_your_api_key_here" \
  -H "Content-Type: application/json"
```

### Format de la clé

Les clés API FluenzR suivent ce format :

```
flz_sk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- `flz` : Préfixe FluenzR
- `sk` : Secret key
- `xxx...` : 32 caractères alphanumériques

## Exemples par langage

### cURL

```bash
curl -X GET "https://api.fluenzr.co/v1/contacts" \
  -H "Authorization: Bearer flz_sk_abc123..." \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('https://api.fluenzr.co/v1/contacts', {
  headers: {
    'Authorization': 'Bearer flz_sk_abc123...',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
```

### JavaScript (axios)

```javascript
import axios from 'axios';

const client = axios.create({
  baseURL: 'https://api.fluenzr.co/v1',
  headers: {
    'Authorization': 'Bearer flz_sk_abc123...'
  }
});

const { data } = await client.get('/contacts');
```

### Python (requests)

```python
import requests

headers = {
    'Authorization': 'Bearer flz_sk_abc123...',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://api.fluenzr.co/v1/contacts',
    headers=headers
)

data = response.json()
```

### PHP

```php
<?php
$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'https://api.fluenzr.co/v1/contacts',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer flz_sk_abc123...',
        'Content-Type: application/json'
    ]
]);

$response = curl_exec($ch);
$data = json_decode($response, true);
```

### Ruby

```ruby
require 'net/http'
require 'json'

uri = URI('https://api.fluenzr.co/v1/contacts')
http = Net::HTTP.new(uri.host, uri.port)
http.use_ssl = true

request = Net::HTTP::Get.new(uri)
request['Authorization'] = 'Bearer flz_sk_abc123...'
request['Content-Type'] = 'application/json'

response = http.request(request)
data = JSON.parse(response.body)
```

## Gérer vos clés API

### Voir les clés existantes

Dans **Paramètres** > **API**, consultez la liste de vos clés :

| Nom | Créée le | Dernière utilisation | Actions |
|-----|----------|---------------------|---------|
| Production | 01/01/2025 | 10/01/2025 | Révoquer |
| Dev/Test | 05/01/2025 | 08/01/2025 | Révoquer |

### Révoquer une clé

1. Cliquez sur **Révoquer** à côté de la clé
2. Confirmez la révocation

> **🚨 Danger**
La révocation est immédiate et irréversible. Toutes les applications utilisant cette clé cesseront de fonctionner.

### Bonnes pratiques

#### Une clé par environnement

| Environnement | Clé | Droits |
|---------------|-----|--------|
| Production | flz_sk_prod_xxx | Tous |
| Staging | flz_sk_stag_xxx | Tous |
| Développement | flz_sk_dev_xxx | Lecture seule |

#### Ne jamais exposer les clés

❌ **Ne jamais faire :**
- Commiter dans un repo Git
- Inclure côté client (frontend)
- Partager par email/chat

✅ **Toujours faire :**
- Utiliser des variables d'environnement
- Stocker dans un gestionnaire de secrets
- Garder côté serveur uniquement

#### Variables d'environnement

```bash
# .env (ne pas commiter)
FLUENZR_API_KEY=flz_sk_abc123...
```

```javascript
// Node.js
const apiKey = process.env.FLUENZR_API_KEY;
```

```python
# Python
import os
api_key = os.environ.get('FLUENZR_API_KEY')
```

## Erreurs d'authentification

### 401 Unauthorized

```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or missing API key"
  }
}
```

**Causes possibles :**
- Clé API manquante
- Clé API invalide
- Clé API révoquée

### 403 Forbidden

```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "API access requires Pro plan"
  }
}
```

**Causes possibles :**
- Compte en pause après la fin de l'essai (API non disponible)
- Clé API sans les permissions nécessaires

## Sécurité

### Rotation des clés

Changez régulièrement vos clés API :

1. Générez une nouvelle clé
2. Mettez à jour vos applications
3. Vérifiez que tout fonctionne
4. Révoquez l'ancienne clé

### Monitoring

Surveillez l'utilisation de vos clés :
- Vérifiez la "dernière utilisation" régulièrement
- Identifiez les clés inutilisées
- Détectez les utilisations suspectes

### En cas de compromission

Si une clé est compromise :

1. **Révoquez immédiatement** la clé dans FluenzR
2. Générez une nouvelle clé
3. Mettez à jour vos applications
4. Analysez les logs pour détecter une utilisation malveillante
5. Contactez le support si nécessaire
