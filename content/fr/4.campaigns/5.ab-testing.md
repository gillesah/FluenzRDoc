# A/B Testing

L'A/B testing vous permet de comparer différentes versions de vos emails pour identifier ce qui fonctionne le mieux.

> **ℹ️ Info**
L'A/B testing est inclus dans le forfait Pro.

## Qu'est-ce que l'A/B Testing ?

L'A/B testing (ou split testing) consiste à :
1. Créer deux versions (A et B) d'un email
2. Envoyer chaque version à une partie de vos contacts
3. Mesurer quelle version performe le mieux
4. Utiliser ces apprentissages pour vos futures campagnes

## Ce que vous pouvez tester

### Objets d'email

L'élément le plus impactant sur le taux d'ouverture.

**Exemples de tests :**
| Version A | Version B |
|-----------|-----------|
| Question rapide | {{firstName}}, question rapide |
| Améliorer vos ventes | 3 techniques pour doubler vos ventes |
| Invitation | Vous êtes invité(e) |

### Contenu de l'email

Impact sur le taux de clic et de réponse.

**Exemples de tests :**
- Longueur (court vs détaillé)
- Ton (formel vs conversationnel)
- Structure (paragraphes vs listes)
- CTA (call-to-action)

## Créer un A/B test

### 1. Activer l'A/B test

Dans l'éditeur de workflow :
1. Cliquez sur un nœud Email
2. Activez l'option **A/B Test**
3. Une version B est automatiquement créée

### 2. Configurer les versions

**Version A :**
- Remplissez l'objet A
- Rédigez le contenu A

**Version B :**
- Cliquez sur l'onglet "Version B"
- Remplissez l'objet B
- Rédigez le contenu B

### 3. Définir la répartition

| Paramètre | Description | Recommandation |
|-----------|-------------|----------------|
| **Répartition** | % de contacts pour chaque version | 50/50 |
| **Critère de succès** | Métrique à optimiser | Taux d'ouverture |

### 4. Option : Envoi automatique du gagnant

Activez cette option pour :
1. Tester sur un échantillon (ex: 20% des contacts)
2. Attendre les résultats (ex: 24h)
3. Envoyer automatiquement la version gagnante aux 80% restants

## Métriques de comparaison

### Taux d'ouverture

Pertinent pour tester les objets.

| Version | Envoyés | Ouverts | Taux |
|---------|---------|---------|------|
| A | 500 | 125 | 25% |
| B | 500 | 175 | **35%** |

→ Version B gagnante (+40% d'ouvertures)

### Taux de clic

Pertinent pour tester le contenu et les CTA.

| Version | Ouverts | Clics | Taux |
|---------|---------|-------|------|
| A | 125 | 15 | 12% |
| B | 175 | 14 | 8% |

→ Version A gagnante pour le taux de clic

### Taux de réponse

La métrique ultime pour la prospection.

| Version | Envoyés | Réponses | Taux |
|---------|---------|----------|------|
| A | 500 | 8 | 1.6% |
| B | 500 | 15 | **3%** |

→ Version B gagnante pour les réponses

## Analyser les résultats

### Signification statistique

Un résultat est fiable si :
- L'échantillon est suffisant (>100 par version)
- La différence est significative (>10% d'écart)
- Le test a duré assez longtemps (>48h)

> **⚠️ Attention**
Avec de petits échantillons, les résultats peuvent être dus au hasard. Attendez d'avoir assez de données avant de conclure.

### Interprétation

| Écart | Interprétation |
|-------|----------------|
| <5% | Pas de différence significative |
| 5-15% | Tendance à confirmer |
| >15% | Différence significative |

## Bonnes pratiques

### Ne testez qu'un élément

Pour savoir ce qui fait la différence, ne changez qu'une chose :

| ❌ Mauvais | ✅ Bon |
|-----------|-------|
| Objet différent + Contenu différent | Seulement l'objet |
| Tout est différent | Une variable à la fois |

### Échantillon suffisant

| Taille liste | Échantillon test recommandé |
|--------------|----------------------------|
| <500 | Test sur 100% (50/50) |
| 500-2000 | Test sur 50% |
| >2000 | Test sur 20-30% |

### Durée du test

Attendez assez longtemps pour avoir des résultats fiables :

| Type d'email | Durée minimum |
|--------------|---------------|
| Prospection | 48-72h |
| Newsletter | 24-48h |
| Urgent | 12-24h |

### Documentez vos tests

Tenez un journal de vos A/B tests :
- Hypothèse de départ
- Ce qui a été testé
- Résultats chiffrés
- Conclusion actionnable

## Idées de tests

### Objets à tester

| Élément | Exemple A | Exemple B |
|---------|-----------|-----------|
| Personnalisation | "Question" | "{{firstName}}, question" |
| Question vs Affirmation | "Comment augmenter vos ventes ?" | "Augmentez vos ventes de 30%" |
| Longueur | "Disponible cette semaine ?" | "Êtes-vous disponible pour un call de 15 min cette semaine ?" |
| Émoji | "Question rapide" | "Question rapide 👋" |
| Urgence | "Une idée pour vous" | "Cette semaine uniquement" |

### Contenus à tester

| Élément | Version A | Version B |
|---------|-----------|-----------|
| Longueur | 3 paragraphes | 1 paragraphe |
| CTA | "Répondez à cet email" | "Cliquez ici pour réserver un créneau" |
| Social proof | Sans témoignage | Avec témoignage client |
| Format | Texte plein | Liste à puces |

## FAQ

### Puis-je faire un test A/B/C ?

Non, FluenzR supporte uniquement les tests à 2 versions. Pour tester 3 options, faites des tests successifs.

### Le test fonctionne-t-il sur les relances ?

Oui, chaque email de la séquence peut avoir son propre A/B test.

### Comment les contacts sont-ils répartis ?

Aléatoirement. Chaque contact est assigné à une version au moment de l'envoi.

### Puis-je modifier un test en cours ?

Non, modifier un test en cours fausserait les résultats. Créez une nouvelle campagne si nécessaire.
