# Analytics

FluenzR vous offre des analytics complets pour mesurer et optimiser vos campagnes.

## Vue d'ensemble

### Dashboard campagne

Pour chaque campagne, accédez aux statistiques en cliquant sur l'onglet **Statistiques**.

### Métriques principales

| Métrique | Description | Formule |
|----------|-------------|---------|
| **Envoyés** | Nombre d'emails envoyés | - |
| **Délivrés** | Emails arrivés à destination | Envoyés - Bounces |
| **Ouvertures** | Contacts ayant ouvert | Ouvertures uniques |
| **Clics** | Contacts ayant cliqué | Clics uniques |
| **Réponses** | Contacts ayant répondu | Réponses détectées |
| **Désinscriptions** | Contacts désinscrits | - |
| **Bounces** | Emails non délivrés | - |

## Taux de performance

### Taux d'ouverture

```
Taux d'ouverture = Ouvertures uniques / Délivrés × 100
```

| Performance | Taux |
|-------------|------|
| Excellent | >40% |
| Bon | 25-40% |
| Moyen | 15-25% |
| Faible | <15% |

> Le taux d'ouverture repose sur un pixel de suivi, assimilé à un traceur soumis à
> consentement par la CNIL depuis 2026. Vous pouvez le couper dans les paramètres du
> compte, et vos destinataires peuvent s'y opposer individuellement. Voir
> [Suivi des ouvertures et consentement](/docs/help/open-tracking-consent).

### Taux de clic

```
Taux de clic = Clics uniques / Délivrés × 100
```

| Performance | Taux |
|-------------|------|
| Excellent | >5% |
| Bon | 2-5% |
| Moyen | 1-2% |
| Faible | <1% |

### Taux de réponse

```
Taux de réponse = Réponses / Délivrés × 100
```

| Performance | Taux |
|-------------|------|
| Excellent | >5% |
| Bon | 2-5% |
| Moyen | 1-2% |
| Faible | <1% |

### Taux de bounce

```
Taux de bounce = Bounces / Envoyés × 100
```

| Performance | Taux |
|-------------|------|
| Excellent | <2% |
| Acceptable | 2-5% |
| Problématique | >5% |

> **⚠️ Attention**
Un taux de bounce >5% peut impacter votre délivrabilité. Nettoyez votre liste de contacts.

## Interpréter vos résultats

### Bon taux d'ouverture, faible taux de clic

**Diagnostic :** L'objet attire mais le contenu ne convainc pas.

**Actions :**
- Améliorez votre proposition de valeur
- Ajoutez un CTA plus clair
- Testez un contenu plus court

### Faible taux d'ouverture

**Diagnostic :** L'objet n'incite pas à ouvrir.

**Actions :**
- Personnalisez l'objet avec des variables
- Testez différentes approches (question, chiffre, etc.)
- Vérifiez votre réputation d'expéditeur

### Beaucoup d'ouvertures, peu de réponses

**Diagnostic :** Les prospects sont intéressés mais pas convaincus.

**Actions :**
- Simplifiez votre demande (call court)
- Ajoutez de la preuve sociale
- Rendez l'action plus facile (lien Calendly)

### Taux de bounce élevé

**Diagnostic :** Qualité de liste problématique.

**Actions :**
- Nettoyez votre liste de contacts
- Utilisez un service de validation d'emails
- Vérifiez vos sources de collecte

## Reporting

### Rapport automatique

Recevez un rapport hebdomadaire par email :
1. Allez dans **Paramètres** > **Notifications**
2. Activez **Rapport de campagne**
3. Choisissez la fréquence

### Rapport personnalisé

Créez des rapports sur mesure :
1. Dans la campagne, cliquez sur **Rapport**
2. Sélectionnez la période
3. Choisissez les métriques
4. Exportez en PDF ou CSV

## Comparaison de campagnes

Comparez les performances de plusieurs campagnes :

1. Allez dans **Campagnes**
2. Sélectionnez les campagnes à comparer
3. Cliquez sur **Comparer**

| Métrique | Campagne A | Campagne B | Écart |
|----------|------------|------------|-------|
| Ouvertures | 32% | 28% | +14% |
| Réponses | 3.2% | 2.1% | +52% |
