# Groupes de contacts

Les groupes vous permettent d'organiser vos contacts et de cibler précisément vos campagnes. FluenzR propose deux types de groupes : **statiques** et **dynamiques**.

## Pourquoi utiliser des groupes ?

### Organisation

- Classez vos contacts par source (LinkedIn, Salon, Site web)
- Séparez par secteur d'activité ou taille d'entreprise
- Distinguez les clients des prospects

### Ciblage

- Créez des campagnes spécifiques par segment
- Personnalisez vos messages selon le groupe
- Mesurez les performances par segment

### Gestion

- Exportez facilement un segment
- Appliquez des actions en masse
- Suivez l'évolution de chaque groupe

## Types de groupes

FluenzR propose deux types de groupes pour répondre à différents besoins :

### Groupes statiques

Les groupes statiques sont la méthode traditionnelle de gestion des contacts :

| Caractéristique | Description |
|----------------|-------------|
| **Ajout manuel** | Les contacts sont ajoutés manuellement ou via import |
| **Persistance** | Un contact reste dans le groupe jusqu'à retrait explicite |
| **Contrôle total** | Vous décidez exactement qui fait partie du groupe |
| **Cas d'usage** | Listes fixes, imports CSV, segments one-shot |

### Groupes dynamiques

Les groupes dynamiques permettent l'inscription automatique aux campagnes :

| Caractéristique | Description |
|----------------|-------------|
| **Inscription automatique** | Nouveaux contacts automatiquement inscrits aux campagnes actives |
| **Temps réel** | Dès qu'un contact est ajouté au groupe, il rejoint les campagnes liées |
| **Évolutif** | Parfait pour les flux continus (API, formulaires, enrichissement) |
| **Cas d'usage** | Leads entrants, workflows automatisés, campagnes continues |

> **💡 Conseil**
> Utilisez les groupes dynamiques pour les campagnes de nurturing continu où de nouveaux contacts arrivent régulièrement.

## Créer un groupe

### 1. Accéder à la création

1. Allez dans **Contacts**
2. Cliquez sur **Groupes** dans la barre latérale
3. Cliquez sur **+ Nouveau groupe**

### 2. Configurer le groupe

| Champ | Description | Exemple |
|-------|-------------|---------|
| **Nom** | Identifiant du groupe | "Leads LinkedIn Q4" |
| **Description** | Note explicative (optionnel) | "Contacts collectés via LinkedIn en Q4 2024" |
| **Type** | Statique ou Dynamique | Dynamique |
| **Couleur** | Couleur d'identification | Bleu |

### 3. Choisir le type

#### Groupe statique
Sélectionnez **Statique** si :
- Vous importez une liste fixe de contacts
- Vous voulez un contrôle manuel total
- La liste ne changera pas fréquemment

#### Groupe dynamique
Sélectionnez **Dynamique** si :
- De nouveaux contacts arrivent régulièrement (API, formulaires)
- Vous voulez qu'ils soient automatiquement inscrits aux campagnes
- Vous avez des campagnes de nurturing continues

### 4. Enregistrer

Cliquez sur **Créer** pour finaliser.

## Fonctionnement des groupes dynamiques

### Inscription automatique aux campagnes

Quand un contact est ajouté à un groupe **dynamique** :

1. FluenzR vérifie si des campagnes actives sont liées à ce groupe
2. Si oui, le contact est automatiquement inscrit à ces campagnes
3. Le workflow de la campagne démarre au cycle d'envoi suivant, soit moins d'une minute après

```
Nouveau contact → Groupe dynamique → Campagne active → Workflow démarre
```

### Conditions requises

Pour que l'inscription automatique fonctionne, le contact doit :

- ✅ Avoir une adresse email valide
- ✅ Être dans un groupe de type **DYNAMIC**
- ✅ Avoir le statut **ACTIVE**
- ✅ Ne pas être déjà inscrit à la campagne

### Exemple de workflow

1. Vous créez un groupe dynamique "Leads Inbound"
2. Vous créez une campagne de nurturing et l'associez à ce groupe
3. Vous lancez la campagne
4. Chaque nouveau lead ajouté au groupe (via API, import, formulaire) :
   - Est automatiquement inscrit à la campagne
   - Reçoit le premier email du workflow
   - Progresse dans la séquence

> **⚠️ Attention**
> Un groupe dynamique peut être lié à plusieurs campagnes actives. Chaque nouveau contact sera inscrit à **toutes** les campagnes actives liées au groupe.

## Ajouter des contacts à un groupe

### Méthode 1 : À la création

Lors de la création ou l'import de contacts, sélectionnez le groupe de destination.

### Méthode 2 : Depuis la liste des contacts

1. Sélectionnez les contacts (cases à cocher)
2. Cliquez sur **Actions** > **Ajouter au groupe**
3. Sélectionnez le groupe
4. Confirmez

### Méthode 3 : Depuis la fiche contact

1. Ouvrez la fiche d'un contact
2. Dans la section "Groupes", cliquez sur **+**
3. Sélectionnez le groupe

### Méthode 4 : Via l'API

Pour les groupes dynamiques, l'API est souvent la méthode privilégiée :

```bash
POST /api/v1/contacts
{
  "email": "nouveau@example.com",
  "firstName": "Jean",
  "lastName": "Dupont",
  "groupId": "uuid-du-groupe-dynamique"
}
```

Le contact sera automatiquement inscrit aux campagnes actives liées au groupe.

## Retirer des contacts d'un groupe

### Depuis la liste

1. Filtrez par le groupe concerné
2. Sélectionnez les contacts à retirer
3. Cliquez sur **Actions** > **Retirer du groupe**
4. Confirmez

### Depuis la fiche contact

1. Ouvrez la fiche du contact
2. Dans la section "Groupes", cliquez sur la croix à côté du groupe
3. Confirmez

> **ℹ️ Info**
> Retirer un contact d'un groupe ne le supprime pas de FluenzR. Il reste dans votre base de contacts.

## Utiliser les groupes dans les campagnes

### Ajouter un groupe entier

1. Créez ou éditez une campagne
2. Cliquez sur **Ajouter des contacts**
3. Sélectionnez l'onglet **Groupes**
4. Cochez le(s) groupe(s) souhaité(s)
5. Confirmez

### Lier un groupe dynamique

Pour les groupes dynamiques, le lien avec la campagne est particulièrement important :

1. Créez une campagne et ajoutez le groupe dynamique
2. **Lancez la campagne** (statut RUNNING)
3. Tous les nouveaux contacts ajoutés au groupe seront automatiquement inscrits

### Exclure un groupe

Dans certains cas, vous voulez cibler un groupe mais en exclure un autre :

1. Ajoutez le groupe principal
2. Cliquez sur **Exclure des contacts**
3. Sélectionnez le groupe à exclure

Exemple : Cibler "Tous les prospects" mais exclure "Clients actuels"

## Vue des groupes dans les campagnes

Dans la vue détaillée d'une campagne, l'onglet **Vue d'ensemble** affiche :

- Les groupes de contacts avec leurs statistiques
- Nombre de contacts par groupe
- Taux d'ouverture et de clics par groupe
- Badge "Dynamique" pour les groupes dynamiques

Cliquez sur un groupe pour voir les contacts individuels et leurs métriques.

## Bonnes pratiques

### Nommage

Utilisez des conventions de nommage claires :

| ✅ Bon | ❌ Mauvais |
|--------|-----------|
| Leads LinkedIn 2024 | Groupe 1 |
| Clients actifs | Test |
| Prospects Fintech | Jean |
| [DYN] Inbound Leads | Dynamique |

> **💡 Conseil**
> Préfixez vos groupes dynamiques avec [DYN] pour les identifier facilement.

### Structure

Organisez vos groupes logiquement :

```
Par source :
├── [DYN] LinkedIn Inbound
├── [DYN] Site web Formulaire
├── Salon TechDays 2024
└── Import CSV Janvier

Par secteur :
├── Fintech
├── SaaS
├── E-commerce
└── Services

Par statut :
├── [DYN] Nouveaux prospects
├── Prospects qualifiés
├── Clients actifs
└── Churned
```

### Quand utiliser chaque type

| Situation | Type recommandé |
|-----------|-----------------|
| Import ponctuel de contacts | Statique |
| Flux continu via API | Dynamique |
| Formulaire de capture | Dynamique |
| Liste d'un événement | Statique |
| Campagne de nurturing continue | Dynamique |
| Campagne one-shot | Statique |

### Maintenance

- Revoyez vos groupes régulièrement
- Archivez ou supprimez les groupes obsolètes
- Fusionnez les groupes redondants
- Vérifiez les campagnes liées aux groupes dynamiques

## Actions en masse sur un groupe

Depuis la page d'un groupe, vous pouvez :

| Action | Description |
|--------|-------------|
| **Exporter** | Télécharger les contacts en CSV |
| **Ajouter à une campagne** | Ajouter tous les contacts |
| **Appliquer des tags** | Ajouter des tags à tous |
| **Supprimer** | Supprimer tous les contacts du groupe |

> **⚠️ Attention**
> La suppression des contacts d'un groupe les retire définitivement de FluenzR, pas seulement du groupe.

## Statistiques par groupe

Dans la page du groupe, consultez :

- Nombre total de contacts
- Contacts actifs vs inactifs
- Taux d'engagement moyen
- Dernière campagne envoyée
- Type de groupe (Statique/Dynamique)
- Nombre de campagnes actives liées (pour les groupes dynamiques)
