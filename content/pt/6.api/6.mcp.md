# Connect an AI (MCP)

The Model Context Protocol (MCP) lets an AI such as Claude or ChatGPT drive your FluenzR account. The AI prepares, you validate: a campaign launch waits for your approval on the **To approve** page, and every write action is logged in "AI activity".

## Server address

```
https://app.fluenzr.co/api/mcp
```

You sign in with your FluenzR account (OAuth): no key to copy. The **Connection** page of the app shows this address and the steps below.

## Claude.ai and Claude Desktop

1. Open **Settings**, then **Connectors**.
2. Click **Add custom connector**.
3. Paste the MCP server address.
4. Sign in to FluenzR when the authorization window opens.

## Claude Code

```bash
claude mcp add --transport http fluenzr https://app.fluenzr.co/api/mcp
```

In Claude Code, type `/mcp`, pick `fluenzr` and authenticate.

## ChatGPT (developer mode)

1. In ChatGPT, open **Settings**, then **Connectors**, and turn on **developer mode**.
2. Create a custom connector and paste the MCP server address.
3. Sign in to FluenzR when the authorization window opens.

ChatGPT's interface changes often: if labels differ, look for the option to add a custom MCP connector.

## First message to paste

> You are connected to my FluenzR account. Start by listing my sending mailboxes with list_email_accounts and summarise their limits. Rules: you prepare, I validate. You create the groups and campaign drafts, then call start_campaign: the launch waits for my approval. You send no reply to my contacts.

For a campaign mixing LinkedIn and email, the AI creates the draft then adds the steps in order (LinkedIn step, wait, condition, email).

## Your approval before launch

On the **Connection** page, the "My approval before launch" option asks for your approval before a connected AI launches a campaign. It is on by default.
