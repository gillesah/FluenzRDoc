# Analytics

O FluenzR oferece analytics completos para medir e otimizar suas campanhas.

## Visão geral

### Painel da campanha

Para cada campanha, acesse estatísticas clicando na aba **Estatísticas**.

### Métricas principais

| Métrica | Descrição | Fórmula |
|--------|-------------|---------|
| **Enviados** | Número de emails enviados | - |
| **Entregues** | Emails que chegaram ao destino | Enviados - Bounces |
| **Aberturas** | Contatos que abriram | Aberturas únicas |
| **Cliques** | Contatos que clicaram | Cliques únicos |
| **Respostas** | Contatos que responderam | Respostas detectadas |
| **Descadastros** | Contatos descadastrados | - |
| **Bounces** | Emails não entregues | - |

## Taxas de desempenho

### Taxa de abertura

```
Taxa de abertura = Aberturas únicas / Entregues × 100
```

| Desempenho | Taxa |
|-------------|------|
| Excelente | >40% |
| Bom | 25-40% |
| Médio | 15-25% |
| Baixo | <15% |

### Taxa de clique

```
Taxa de clique = Cliques únicos / Entregues × 100
```

| Desempenho | Taxa |
|-------------|------|
| Excelente | >5% |
| Bom | 2-5% |
| Médio | 1-2% |
| Baixo | <1% |

### Taxa de resposta

```
Taxa de resposta = Respostas / Entregues × 100
```

| Desempenho | Taxa |
|-------------|------|
| Excelente | >5% |
| Bom | 2-5% |
| Médio | 1-2% |
| Baixo | <1% |

### Taxa de bounce

```
Taxa de bounce = Bounces / Enviados × 100
```

| Desempenho | Taxa |
|-------------|------|
| Excelente | <2% |
| Aceitável | 2-5% |
| Problemático | >5% |

> **Atenção**
Uma taxa de bounce >5% pode impactar sua entregabilidade. Limpe sua lista de contatos.

## Interpretar seus resultados

### Boa taxa de abertura, baixa taxa de clique

**Diagnóstico:** O assunto atrai mas o conteúdo não convence.

**Ações:**
- Melhore sua proposta de valor
- Adicione um CTA mais claro
- Teste conteúdo mais curto

### Baixa taxa de abertura

**Diagnóstico:** O assunto não incentiva a abertura.

**Ações:**
- Personalize o assunto com variáveis
- Teste diferentes abordagens (pergunta, número, etc.)
- Verifique sua reputação de remetente

### Muitas aberturas, poucas respostas

**Diagnóstico:** Prospects estão interessados mas não convencidos.

**Ações:**
- Simplifique seu pedido (chamada curta)
- Adicione prova social
- Facilite a ação (link Calendly)

### Alta taxa de bounce

**Diagnóstico:** Qualidade da lista é problemática.

**Ações:**
- Limpe sua lista de contatos
- Use um serviço de validação de emails
- Verifique suas fontes de coleta
